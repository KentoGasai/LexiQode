# LexiQode

IDE с ИИ-ассистентом. Ассистент работает на **твоём** адресе модели: любой сервер,
совместимый с OpenAI `/chat/completions`. Ни подписки, ни аккаунта, ни чужого
посредника.

[English version](README.en.md)

## Из чего состоит

| Часть | Что это |
|---|---|
| Окно | собственный интерфейс, отдаваемый по внутренней схеме `app://` |
| Редактор | Monaco — компонент редактирования из VS Code, как библиотека |
| Терминал | xterm.js и оболочка, подключённая через каналы ввода-вывода |
| Ассистент | самостоятельное ядро на Python; окно его запускает и контролирует |
| Модель | любой OpenAI-совместимый адрес, который ты укажешь |
| Язык интерфейса | русский и английский, переключается на ходу |

## Требования

* Windows 10 или 11, 64-бит.
* **Python 3.11 или новее в `PATH`** — нужен ассистенту. Без него редактор
  работает, и приложение честно скажет, чего не хватает.
* Права администратора не нужны: это папка, которую распаковывают и запускают.
* Node.js 24 — только если собираешь приложение сам.

## Установка и запуск

**Самый простой способ.** Распакуй архив и запусти `LexiQode.exe`:

```
dist\LexiQode-0.1.0-win32-x64.zip
```

Рядом лежит файл `.sha256` с контрольной суммой — её же печатает сборка, ей можно
проверить скачанное.

**Установить в профиль и получить ярлыки** (без прав администратора):

```powershell
cd F:\Gitea\LexiQode2
powershell -ExecutionPolicy Bypass -File scripts\run-app.ps1 -Deploy
powershell -ExecutionPolicy Bypass -File scripts\create-shortcuts.ps1
```

**Запуск из исходников** (когда правишь код):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run-app.ps1 -Source
```

**Собрать архив заново:**

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-app.ps1
```

Скрипт прогоняет тесты, собирает папку и архив в `dist\`. Флаг `-SkipTests`
пропускает тесты.

## Первый запуск

Приложение **ничего не открывает само**. Ты увидишь экран с кнопкой «Открыть
папку» и списком недавних. Открыть папку можно четырьмя способами:

* кнопкой на этом экране;
* кликом по надписи «папка не открыта» слева внизу, в строке состояния;
* `Ctrl+K Ctrl+O`;
* `Ctrl+Shift+P` → «Открыть папку…»;
* передать путь при запуске: `LexiQode.exe F:\мой\проект` (нужен абсолютный путь).

Затем настрой модель — без неё ассистент ответит, что модель не выбрана.

## Настройка модели

Открой панель ассистента (`Ctrl+Shift+A`) и нажми шестерёнку. Заполни:

| Поле | Что писать |
|---|---|
| адрес | базовый URL, например `https://api.example.com/v1` или `http://127.0.0.1:11434/v1` |
| ключ API | хранится на твоей машине и уходит только на этот адрес |
| модель | идентификатор модели |

Список моделей **подтягивается сам**, как только введены адрес и ключ, —
сохранять заранее не нужно. Если адрес недоступен или список пуст, форма покажет
причину и кнопку «Спросить снова».

Сканирование идёт по адресу `GET {адрес}/models` — так устроен OpenAI-совместимый
протокол. Поэтому базовый адрес должен быть таким, чтобы этот путь получался
правильным.

Те же настройки можно задать без окна:

```powershell
$env:LEXIQODE_BASE_URL = 'https://api.example.com/v1'
$env:LEXIQODE_API_KEY  = 'sk-...'
$env:LEXIQODE_MODEL    = 'имя-модели'
python -m lexiqode doctor     # проверяет адрес, ключ и модель
```

Где что лежит:

* `%APPDATA%\LexiQode\settings.json` — агент: адрес, ключ, модель, лимиты;
* `%APPDATA%\LexiQode\app-settings.json` — окно: раскладка, тема, язык,
  открытые вкладки;
* `%LOCALAPPDATA%\LexiQode` — история разговоров и прочие данные.

## Режимы работы

Режим выбирается в композере, внизу панели ассистента — выпадающим списком с
иконками. Это решение о том, что разрешено следующему сообщению. Режимы
проверяются в ядре: запрещённый инструмент убирается из схем **и** отклоняется
реестром, поэтому режим нельзя обойти уговорами модели.

| Режим | Читает файлы | Правит | Запускает команды |
|---|---|---|---|
| Агент | да | да | да |
| Вопрос | да | нет | нет |
| План | да | нет | нет |
| Отладка | да | да | да |
| Ревью | да | нет | нет |

## Смена языка интерфейса

Строка «язык окна» в настройках ассистента или команда «Язык окна: изменить» в
палитре: «как в системе» → русский → английский → снова «как в системе». По
умолчанию язык берётся у системы.

Словари — это обычные файлы данных: `app/src/shared/i18n.ru.json` и
`app/src/shared/i18n.en.json`. Чтобы добавить язык, положи такой же файл и
допиши код в список в `app/src/shared/i18n.js`: тест сверяет файлы ключ за ключом
и не даст им разойтись.

## Что умеет

Проводник (создать, переименовать, удалить в корзину, показать в проводнике);
редактор Monaco (подсветка, вкладки, признак несохранённого, сохранение с теми же
переводами строк, поиск в файле); быстрое открытие файла; поиск по всем файлам с
отменой; контроль версий (подготовленное и изменённое раздельно, diff,
подготовить, снять, отменить, коммит, переключение ветки); терминал с настоящей
сессией PowerShell; ассистент с потоковым ответом, отдельно показанными
рассуждениями, строками вызовов инструментов, подтверждениями и остановкой;
изменяемая и восстанавливаемая раскладка; тёмная и светлая темы.

## Чего не делает

* **Терминал — консоль команд.** Полноэкранные программы (`vim`, `top`) в нём не
  работают: у оболочки, подключённой через каналы, нет псевдоконсоли. Всё, что
  читает команду и печатает строки, работает.
* **Нет сторонних расширений.** Языки, темы и команды даёт само приложение.
* **Языковая поддержка — от Monaco.** Настоящие языковые службы есть для
  TypeScript, JavaScript, JSON, CSS и HTML; остальным — подсветка, скобки и
  сворачивание.
* **Одна папка на окно.**
* **Никакой телеметрии.** Окно вообще не имеет доступа в сеть (`connect-src
  'none'`); сеть использует только ядро — и только для обращений к твоему адресу.
* Часть сообщений приходит из ядра и печатается так, как их сформулировало ядро.

## Тесты

```powershell
cd core;  python -m pytest tests -q      # агент, его инструменты и протокол
cd app;   npm test                       # 111 тестов: общая логика и контракты окна
```

Дополнительно есть два замера, которые запускают приложение и опрашивают его:

```powershell
node app\scripts\probe-window.cjs        # интерфейс: дерево, редактор, поиск, терминал, режимы, форма настроек
node app\scripts\probe-chat.cjs          # поднимает заглушку OpenAI и гоняет через неё ядро
```

Тесты окна включают живой тест терминала (запускается настоящий PowerShell) и
статический контроль контрактов: элементы, каналы, импорты, набор ключей в обоих
словарях и соответствие маршрутов ядра тем, которые вызывает окно.

## Сборка и публикация

CI не используется — сборки делаются локально:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-app.ps1
```

На выходе: папка сборки, архив `dist\LexiQode-<версия>-win32-x64.zip` и файл с
контрольной суммой. Версия берётся из `app/package.json`.

Чтобы выложить сборку на GitHub, прикрепи архив к релизу (нужен `gh`):

```powershell
gh release create v0.1.0 `
  dist\LexiQode-0.1.0-win32-x64.zip `
  dist\LexiQode-0.1.0-win32-x64.zip.sha256 `
  --title "LexiQode 0.1.0" --notes "Первая сборка"
```

Для уже существующего релиза: `gh release upload v0.1.0 путь\к\архиву`.

## Структура репозитория

```
app/                  окно
  src/main/           окно, IPC, рабочая папка, поиск, git, терминал, мост к агенту
  src/preload/        весь набор вызовов, доступных странице
  src/renderer/       интерфейс: разметка, стили, модули
  src/shared/         логика для обеих сторон и словари языков
  test/               тесты окна
  scripts/            вендоринг браузерных пакетов и замеры
core/                 агент на Python со своими тестами
scripts/              сборка, запуск, ярлыки
docs/protocol.md      протокол между окном и ядром
```
